О ПРОЕКТЕ

GTNH Craft Calculator — инструмент для расчёта производственных линий в духе GregTech: New Horizons. Добавляйте рецепты, указывайте тир машины, энергию, шансы выхода — калькулятор учтёт ускорение (×2 за тир), рост энергии (×4 за тир) и вероятностные выходы. Группируйте рецепты, тегируйте ресурсы, экспортируйте/импортируйте данные.

Вдохновлено shadowtheage.github.io/gtnh.

ИНСТРУКЦИЯ
1. Добавление рецепта

Заполните Название, выберите режим (тики или скорость).

2. Тиры и энергия

Выберите начальный тир и тир машины. Укажите EU/t на начальном тире.

3. Шанс выхода, группы, теги

Для выходов — шанс (0–100%), для группировки — имя группы, для категоризации — теги ресурсов.

4. Поиск

Строка поиска над итоговой таблицей фильтрует ресурсы в реальном времени.

Пример: выплавка стали в EBF
Рецепт: Выплавка стали
Тики: 100 / LV→MV
EU/t база: 120
Вход: Железо ×1, Уголь ×1
Выход: Сталь ×1 (100%)

На MV: скорость = 0.4 оп/с, энергия = 480 EU/t.

🆕 Возможности

📁 Группы: сворачивайте рецепты по группам.

💾 Экспорт/Импорт: кнопки всегда доступны в шапке «Добавленных рецептов» — даже если список пуст.

🔍 Поиск: фильтр над итоговой таблицей.

🏷 Теги ресурсов: при вводе названия ресурса появляется выпадающий список с уже существующими тегами. Теги видны в итоговой таблице.

🖱 ПКМ: по ресурсу в таблице → быстрое добавление рецепта или применение тега.
